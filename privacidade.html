Política de Privacidade

Robo Casos do Corvo — atualizada em 25/09/2026

O "Robo Casos do Corvo" é uma ferramenta de uso exclusivo do canal Casos do Corvo, utilizada somente pelo próprio dono do canal para publicar os vídeos do canal. Ela não é oferecida ao público e não possui outros usuários.

Dados do Google que acessamos

Com a autorização do dono do canal, a ferramenta usa os Serviços de API do YouTube com uma única permissão: enviar vídeos para o canal Casos do Corvo (escopo youtube.upload). Não lemos, coletamos nem armazenamos dados de espectadores, inscritos, comentários, e-mails, contatos ou qualquer outro dado pessoal.

Como os dados são usados e armazenados

O token de acesso fornecido pelo Google fica guardado apenas no servidor privado do canal e é usado exclusivamente para enviar os vídeos (arquivo, título, descrição e tags). Nenhum dado é vendido, compartilhado ou transferido a terceiros, nem usado para publicidade.

Serviços de API do YouTube

Esta ferramenta usa os Serviços de API do YouTube. Ao usá-la, aplicam-se também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Como revogar o acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions ou nas configurações de segurança do Google. Após a revogação, o token deixa de funcionar e é apagado do servidor.
